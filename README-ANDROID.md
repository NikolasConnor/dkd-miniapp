# ДКД — отдельное Android-приложение

Отдельный Android-клиент в ветке `android-prototype`. Основной Telegram Mini App остаётся отдельным клиентом и использует ту же серверную часть и базу Supabase.

## Текущее состояние 0.3.0
- Kotlin + Jetpack Compose, тёмный интерфейс.
- Нативный экран входа по одноразовому коду привязки.
- Код создаёт главный администратор в панели Mini App для конкретного Telegram ID участника.
- Код действует 15 минут и обменивается на серверную сессию один раз.
- Сессия хранится на устройстве в зашифрованном виде с ключом Android Keystore; срок действия — 30 дней, сервер поддерживает отзыв.
- После входа открывается существующий веб-интерфейс ДКД внутри Android WebView.
- Запросы Android-клиента получают Bearer-сессию; Telegram для обычной работы приложения не требуется.
- Разрешена навигация внутри HTTPS-домена ДКД; внешние ссылки открываются системным браузером.
- Поддерживается работа по Wi-Fi и мобильной сети, если они дают доступ к серверу.

## Ограничения
- Если Render или Supabase недоступны из сети пользователя, серверные действия не выполняются. Это не обход белых списков.
- Debug APK предназначен для тестирования и не является подписанной production-сборкой для Google Play.
- Не хранить Supabase secret/service-role key в Android-клиенте.
- Не передавать одноразовый код или токен посторонним; код выдаётся конкретному участнику.

## Сборка
GitHub Actions workflow `.github/workflows/android-apk.yml` собирает debug APK при изменениях Android-проекта.
