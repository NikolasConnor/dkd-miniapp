# ДКД — отдельное Android-приложение

Android-клиент разрабатывается отдельно от Telegram Mini App. Mini App не встраивается в Android и не меняет свой интерфейс. Оба клиента используют общий сервер и данные ДКД.

## Текущее состояние 0.4.0

- Kotlin + Jetpack Compose, самостоятельная тёмная Android-оболочка.
- Нативный экран входа по одноразовому коду привязки.
- Код выдаётся администратором для конкретного участника, действует 15 минут и используется один раз.
- Сессия хранится зашифрованной с помощью Android Keystore; сервер поддерживает отзыв сессии.
- После входа показывается нативная нижняя навигация: Главная, Лента, Чаты, Государство, Профиль.
- Разделы запрашивают данные с backend API с Bearer-сессией; Telegram после привязки не требуется.
- Ошибки сети и сервера показываются внутри приложения, доступно повторное обновление.
- В Android-клиенте больше нет WebView с Telegram Mini App.

## Что ещё не реализовано

Нативная навигация и базовое чтение API — фундамент, а не завершённый функционал социальной сети и государственного симулятора. Полноценные нативные сценарии публикаций, медиа, комментариев, чатов, выборов, законов, документов, уведомлений и администрирования предстоит подключить к отдельным API-экранам. Не следует считать их готовыми только потому, что пункты навигации уже отображаются.

## Ограничения и безопасность

- Если Render или Supabase недоступны из сети пользователя, серверные действия не выполняются.
- Debug APK предназначен для тестирования и не является подписанной production-сборкой для Google Play.
- Секретный ключ Supabase/service-role никогда не должен находиться в Android-клиенте.
- Не передавайте одноразовый код или токен другим людям.

## Сборка

GitHub Actions workflow `.github/workflows/android-apk.yml` собирает debug APK при изменениях Android-проекта.
