# ДКД — отдельное Android-приложение (prototype)

Это независимый Android-клиент. Он не заменяет Telegram Mini App и пока не подключён к Supabase/API.

## Состояние прототипа
- Kotlin + Jetpack Compose.
- Тёмный интерфейс ДКД.
- Навигация между главной, профилем, Думой, Правительством, документами, новостями и настройками.
- Демонстрационные карточки и действия-заглушки.
- Нет авторизации, сетевых запросов, записи голосов или изменения реальных данных.

## Сборка APK
В GitHub Actions запускается workflow `.github/workflows/android-apk.yml`.
Готовый debug APK прикладывается к успешному запуску как artifact `dkd-android-debug-apk`.

Для локальной сборки нужен JDK 17 и Gradle 8.9:
```bash
gradle assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.
