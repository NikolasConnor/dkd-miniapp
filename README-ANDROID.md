# ДКД — отдельное Android-приложение

Нативный Android-клиент виртуального государства ДКД от NEXORA GROUP. Это самостоятельное приложение на Kotlin и Jetpack Compose: Telegram Mini App не встраивается через WebView, а социальный продукт «Чаты» и «Лента» в состав ДКД Android не входят.

## Текущее состояние

- Вход по одноразовому коду привязки через `POST /api/android/auth/redeem`.
- Локальная сессия хранится с использованием Android Keystore.
- Нижняя навигация: Главная, Государство, Документы, Выборы, Профиль.
- Профиль, новости, партии, состав Государственной Думы, выборы и документы загружаются через API ДКД.
- Президентская администрация подключена к production-подтверждённым маршрутам статуса Президента, публикации указов, решений по законам и назначения думских выборов; каждый вызов дополнительно проверяется сервером.
- Экран документов разделяет паспорт, депутатский мандат, удостоверение Президента, указы и подписанные законы.
- Экран выборов пока информационный: отправка голоса не включена, пока серверная проверка права голоса не подтверждает все правила ДКД.
- Не подключённые государственные услуги обозначаются как готовящиеся, а не имитируются как действующие.
- Раздел Президента скрывает управляющие действия без серверных полномочий; роспуск Думы требует дополнительного подтверждения.

## Архитектура и безопасность

- Kotlin + Jetpack Compose, отдельная Android-навигация.
- Общий backend/API с Telegram Mini App, но независимый Android-интерфейс.
- Telegram не требуется после привязки аккаунта.
- Секреты Supabase и service-role key не хранятся в приложении.
- Android-разработка ведётся в ветке `android-dkd-portal-redesign`. Production `main`, Render и база данных не обновляются этой веткой.

## Сборка и ограничения

GitHub Actions workflow `.github/workflows/android-apk.yml` запускает unit-тесты и собирает debug APK. Debug APK предназначен для тестирования и не является подписанным релизом для Google Play.

Успешная CI-сборка подтверждает компиляцию и прохождение автоматических проверок, но не заменяет проверку входа, навигации и API на физическом Android-устройстве. OkHttp уже используется как транспорт; Retrofit и полностью типизированные DTO, Room/offline sync, полноценная реализация всех государственных услуг и физическое device testing остаются отдельными задачами.
