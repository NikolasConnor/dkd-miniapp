# ДКД — отдельное Android-приложение

Отдельный Android-клиент в ветке `android-prototype`. Основной Telegram Mini App и его база не изменяются.

## Текущее состояние 0.2.0
- Kotlin + Jetpack Compose, тёмный интерфейс.
- Прямой HTTPS-запрос к API ДКД по Wi-Fi или мобильной сети.
- Проверка доступности API и отображение типа сети телефона.
- Сетевые разрешения Android добавлены.
- Нет Telegram-зависимости в сетевом запросе проверки.
- Авторизация и персональные данные пока не подключены; государственные операции не выполняются.

## Важный следующий этап
Текущий сервер принимает пользовательские запросы через проверенную Telegram WebApp initData. Нельзя подменять её Telegram ID, хранить Supabase service key в APK или выдавать клиенту административные права. Для полноценного автономного Android-входа сначала требуется отдельная безопасная схема привязки аккаунта и серверных сессий. После этого разделы профиля, документы, новости, партии, парламент и голосования можно подключать к существующим API и той же базе данных.

## Сборка
GitHub Actions workflow `.github/workflows/android-apk.yml` собирает debug APK при изменениях Android-проекта.


## Подключённый режим (Android 0.3.0)

APK открывает основной интерфейс ДКД в Android WebView и использует тот же backend/API и ту же базу Supabase, что и Mini App. Telegram для ежедневной работы приложения не нужен.

### Вход участника
1. Главный администратор открывает Mini App в Telegram и переходит в управление участниками.
2. Открывает карточку нужного участника и нажимает «Выдать код входа в APK».
3. Передаёт одноразовый код участнику лично. Код действует 15 минут и может быть использован один раз.
4. Участник вводит код в Android APK. Сервер выдаёт отдельную сессию на 30 дней.
5. Сессия хранится на устройстве и передаётся серверу через защищённую HttpOnly cookie. Секреты Supabase в APK не помещаются.

### Подготовка сервера
Миграция `supabase/migrations/20261106103518_android_auth.sql` уже применена к текущему Supabase project. Она добавляет только таблицы одноразовых кодов и Android-сессий; существующие данные не удаляет и не меняет.
